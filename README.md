# CLMS · 语文错题本（Chinese Language Mastery System）

拍一张做错的语文卷子，AI 把它拆成「原文 + 小题 + 题型 + 参考答案 + 留白」，你在对话里让它改、在草稿上直接改，确认后入库；之后每周两三次，按时间预算排一份复习卷，打印出来写，写完逐题自评。

CLMS 的架构对标 OMRS（Obsidian Mistake Reconstruction System）：本地运行、核心只用 Python 标准库、SQLite 提交链是唯一事实源、无构建的 ES 模块前端。区别在于它为语文做了专门设计——阅读题以「材料」为单位、默写按空拆题并自动去重、复习是低频的「复习日」节奏。

## 快速开始

需要 Python 3.10 及以上。不需要安装任何依赖；装了 Pillow 的话，AI 识图前会先缩图（大照片更快、更省额度），长截图会自动切段。

```bash
# Windows：双击 run.bat（数据放在 CLMS 目录里）
# macOS / Linux：
./run.sh
# 或者指定数据位置，例如放进 Obsidian 库：
python3 clms_engine.py --vault ~/Obsidian/笔记 serve --open
```

浏览器打开 <http://localhost:8472/>。数据在 `<vault>/语文/.clms/` 下。第一次用先到「设置」填 AI：

| 设置项 | 说明 |
| --- | --- |
| API 地址 | 任何兼容 OpenAI `/chat/completions` 的服务，例如 `https://api.openai.com/v1`、阿里云百炼 `https://dashscope.aliyuncs.com/compatible-mode/v1`、火山方舟、智谱 |
| API Key | 只存在本机 `config.json`，界面上不回显 |
| 模型名 | 必须能看图，例如 `gpt-4o`、`qwen-vl-max`、`doubao-vision-pro`、`glm-4v-plus` |
| 超时 / 同时识别几张 | 慢模型调大超时；遇到限流把并发调小 |
| 输出上限（token） | 默认 16000；长原文或会消耗思考 token 的模型若提示输出被截断，可调高后重试 |

没配 AI 也能用：「手动录入」直接在草稿上填。

## 录入：上传 → 确认页面 → AI 实时执行 → 校对 → 入库

1. **上传**：录入页中间是一个大输入框。把照片拖进来、Ctrl+V 粘贴截图，或点「上传图片」。上传后**不会直接开始**：输入框上方出现页面条，按 AI 读图的顺序排好页（拖动或悬浮出现的箭头）、把拍歪的转正、删掉不要的页、再加几页，给页面写一句说明（「答案页」之类）；在输入框里写的话就是补充说明。然后「开始识别」（合成一份，或切到「每页一份」）。不传图直接在输入框里说话，就是一段普通对话（查改题库、补记复习）。
2. **看 AI 干活**：输入框平滑落到对话底部，对话里像 Harness 一样实时显示——模型的思考逐字出现，它说的话逐字出现，每次工具调用一行（点开看参数和结果），大试卷分给子代理后每个子代理一张卡片（点开看它自己的过程）；右侧草稿随工具调用实时更新。可以随时插话或停止。
   输入框旁的圆环显示上下文占用，悬浮可以看速度、首字延迟、轮数、工具次数和累计 token。
3. **录入记录**：左侧列出所有录入（按日期分段），可以搜索、按进行中 / 待入库 / 已入库 / 回收站筛选、重命名、丢到回收站、恢复、彻底删除；宽屏可以收起。主导航也可以收成图标窄栏。
4. **AI 拆题**：思考片段是否出现取决于模型是否返回推理内容（`reasoning_content` 或 `<think>`）；不返回的模型也会在调用工具前说一句要做什么。关掉 Agent 模式时走旧的一次性流程，只显示排队、处理原图、调用模型等步骤。
   - 现代文、文言文、古诗：拆出标题 / 作者 / 出处 / 原文，再逐题拆出题号、题型、题干、分值、参考答案，并按分值和答案要点估计每题留白几行。题型只从你在「设置 → 复习与打印 → 题型体系」建立的列表选择；没有明确匹配项就显示「未分类」，仍可入库。
   - 文言文：精细到每道小题，不再往下拆。
   - 名句默写：整道题写成带占位符的模板，如 `床前明月光，{书写区域1}。`，另附答案表 `{"1": "疑是地上霜"}`；**入库时每个空就是一道小题**。
   - 图里有答案就照录（标「图中答案」）；图里没有，AI 按阅卷习惯分条补写（标「AI 补写」，建议核对）。
5. **对话修改**：左边是对话，直接说「第 7 题答案按 6 分重写」「第 8 题改成我建立的表达技巧题」「留白再多两行」。AI 回复里会列出改了哪几处，点一下就跳到草稿对应位置并闪一下；不满意点「回到修改前」。发送时可以附上原图让 AI 对照核对。草稿题型下拉可当场「新增题型」并自动选中。
6. **直接改草稿**：右边的草稿就是一张卷面——原文衬线排版，参考答案是红笔，留白是真的答题横线，用 −/+ 调行数。任何字段都能直接改，停手 0.7 秒自动保存；手改也会记在对话里，可以撤销。AI 漏掉的一篇或一组默写，用草稿末尾的「添加板块」补上。
7. **入库**：底栏会列出还缺什么（没有答案、题干为空、默写空没有答案……），全部补齐后点「入库 N 题」。入库后点「录下一份」回到居中输入框。

### 去重

同一道题错两次是常态，CLMS 不会重复建题，而是给已有的题记一次「又错了一次」（调度上按一次「不会」处理）：

- **默写**：按答案的汉字比对，标点、全角半角、前后语境都不影响。答案不足 4 个字（如「之」）时再加上题面前 24 个汉字，避免误并。草稿里每个空旁边会标「新 / 库中已有 · 记又错一次 / 本稿重复 · 跳过」。
- **阅读材料**：先比原文汉字的哈希；不一样时再做相似度比对（汉字二元组重合 ≥ 85%），所以「第二次拍照少了标题行、几个字识别不同」仍会认成同一篇，新题挂到原来那篇下面。
- **阅读小题**：同一篇材料下比题干（保留题号数字，「第③段」和「第⑤段」是两道题）。

## 复习：一周两三次

- **复习日**：默认周二、周五、周日，在「设置」里改。到期日会对齐到复习日，不会出现「周三到期、周五才做」的假逾期。
- **排复习**：进「复习」页就有一份推荐清单：按时间预算（20–90 分钟）、板块、题型，CLMS 按到期、上次评分、录入多久没练、薄弱题型挑题，每道题写明为什么推荐（「逾期 3 天 · 上次『部分』」「新录入 · 5 天未练」「薄弱题型 · 意象作用题」）。同一篇文章里到期的小题尽量一起排，原文只读一遍。不想做的题点 × 移掉会自动换一道；也可以在旁边「从题库挑题」按状态 / 录入时间 / 最近练习 / 上次评分筛选后加入，加入的题一定排上，推荐补足剩下的时间。已经在没做完的复习里的题不会重复推荐。
- **打印预览**：创建复习后先看到真正分页的 A4 卷面，再选择打印或开始复习。点当前题或全部题的「自动适配」，浏览器按答题区域的实际宽度、字体、字号、行高和换行规则排参考答案，测出需要几行；支持 − / 数值 / + 即时调节并重新分页。调节会永久写回题目的默认留白（0–1000 行），连续点击短防抖保存，以后新建复习沿用；仅打开预览不会修改题库。打印与预览共用同一套模板和 CSS。默写同模板的空合并，支持附答案页。
- **自评**：做完在「复习」里一次看一道题：左边是「答题卡」题号（评过的按评分着色），宽屏时原文和题目并排。先对答案（空格），再自评（数字键 0–3，评分档和说明一直摆着）：阅读题四档不会 / 部分 / 基本 / 完整，默写三档不会 / 有错字 / 全对。每道题可以写一句反馈；评错了可以撤销或改评（改评分时反馈保留）。← → 换题。复习记录一直在左栏，不用滚到底找。
- **复习助手**：评分页右边，跟着你正在看的题：随时问思路、采分点；把作答打出来或拍照发给它，点「打分」对照采分点给建议评分和反馈，点「写反馈」写一句复习反馈——点「采用」才会记下。它自己按需去查题目和原文（长文章只读需要的几段），思考过程和每次查阅都显示出来；在卷面上选中一段文字点「引用」，就能针对这段问。
- **算法**：两条记忆曲线。默写始终是「记忆型」；其它题型可在设置里逐个设为记忆型或理解型，新建默认理解型，未分类也按理解型安排。记忆型沿用 OMRS 的间隔重复；理解型做对一次（或连续两次「基本」）就算掌握，衰减慢，掌握后约 4 个月才抽查一次。未分类照常到期复习，但不算入薄弱题型。细节见 `AI/algorithm.md`。

## Agent：对话直连工具调用（默认开）

录入页的对话直接连着一个工具调用的 Agent（仿 Pi）：它通过工具逐题建、查、改草稿，每一步都显示在对话里；你可以随时插话或停止。

- **大试卷**：先通读全卷，再把每个大题（一篇阅读 + 它的小题，或名句默写）交给一个子代理，只告诉它板块、标题和页码；几个子代理并行录，各自只改自己的板块，最后主代理检查补漏。
- **不止录题**：在对话里还能让它查题库、改题、停用 / 删除 / 恢复、补记或修改复习记录、说「入库」；点「新对话」可以不传图直接聊。改正式题目/材料、停用/删除/恢复及改旧复习记录会提交审核，人工批准后才执行。
- 模型需要支持工具调用（function calling）；不支持时到「设置」关掉 Agent 模式，回到一次性识图。

## 其它页面

- **概览**：下一个复习日与两周日历、到期题数和预计时长、四个板块的掌握度、题型薄弱榜（哪类题最容易错）、最近动态。
- **题库**：左边按状态、记忆类型、添加时间、最近练习、上次评分、题型筛选（含「未分类」，每项显示题数），上面按板块、关键词（题干、答案、篇名、出处、题号）筛选；可以按题看，也可以按篇看（每篇的掌握情况一目了然）；按优先级、到期日、掌握度、出错次数、最近练习、录入时间排序，分页加载。批量选择后可以加入复习、停用、恢复、删除。详情里可以改题并给未分类题选择已有题型、停用、删除（「已删除」里可恢复）、跳到同一篇的其它题；复习记录可以补记、改评分、写反馈、撤销、恢复。「复习记录」分页列出全部复习历史，可按板块、评分、时间、有没有反馈筛选。
- **设置 → 复习与打印 → 题型体系**：现代文、文言文、古诗各自管理题型，可新增、重命名、删除、调整顺序，并设为「理解型 / 记忆型」。重命名会同步已有题；删除使用中的题型要选迁移到其它已有题型或「未分类」。新库为空表；旧库首次升级只带入实际用过的题型。
- **设置 → 数据与存储 → 导出脱敏源代码**：把程序源码打成 zip 给 AI 助手看，不依赖 Git、不含你的数据，API Key 会被替换掉（命令行 `python3 clms_engine.py export-source`）。

## 全局助手与审核中心

一级「全局助手」支持持久对话，展示消息、思考、工具参数与结果、Token/上下文统计以及结束状态。它能查题库、材料、学习概况、推荐和 Session，也能创建或修改未入库草稿、查看作文正式稿、追加评价/讨论重点和自由分类。当前页面只传 item/session/作文版本等轻量编号，作为数据上下文。

正式 Session、正式题目/材料修改都先提交统一审核。「审核中心」显示来源、时间、revision、前后对照和计划影响；Session 提案包含标题、分钟数、数量和清单。你可以在原请求字段内修订、批准或拒绝。批准时再次校验当前内容快照，冲突不会覆盖；聊天确认卡与审核中心处理的是同一个操作，重复批准不会重复创建。

在「设置 → AI 助手」开启助手，可单独配置地址/模型/Key；地址和模型留空沿用 AI 识别配置，Key 留空保留已存独立密钥，点“清除独立密钥”才恢复沿用识别 Key。底层仍复用录入 Agent 的模型协议与循环。

## 作文：完整练习与多稿评价

「作文」搜索/新建题目，填写正文和要求，建立一次写作练习（Attempt），上传一稿（Version）的 2–3 张原图后做 OCR。OCR 只转写，保留错字、病句和标点，读不清的标为存疑。人工校对后确认正式正文；修正识别错误仍是同一稿，确认后正文不能被评价覆盖。真正重写请上传下一版：1 版是修改 0 次，2 版是修改 1 次。

每个版本可有多份 0–60 分评价，保留优点、问题、建议及可选自由维度；可以采用其中一份，旧评价永久绑定原稿。讨论重点以简短笔记保存，不自动保存完整聊天。自由分类可任意创建和组合，不要求固定树或分组；版本之间可查看文本增删差异。作文独立于普通错题的记忆曲线。

## 外部 AI / MCP

MCP 是可选功能，普通 CLMS 无需安装它：

```bash
python3 -m pip install -r requirements-mcp.txt
python3 clms_engine.py --vault <目录> serve --mcp-port 18473
```

默认独立服务地址为 `http://127.0.0.1:18473/mcp`，只监听本机。在「设置 → 外部 AI / MCP」创建、修改权限或吊销 Key。明文只在创建时显示一次；磁盘仅存摘要与元数据，Key 与 Web/模型密钥分离。默认 API 权限为学习查询、作文查询、创建草稿；其它按需勾选。每次调用实时检查权限、到期和吊销。所有写工具要求 `request_id`：相同内容重复调用返回同一操作，内容不同报冲突。

外部模型可以读取确认后的作文全文，在获授权时读对应原图，保存 47/60 的评价、下一稿讨论重点和分类，无须再复制粘贴。正式 Session/改题仍返回待审核项，MCP 没有批准自己的工具；网页批准后可查到正式编号。工具/scope 详细清单在 [AI/api.md](AI/api.md)。外部服务若需要远程连接，需自行提供代理和可达地址，并通过 `--mcp-public-url` 登记精确 Host/Origin；此参数不自动建立公网隧道。

## 历史与分区设置

「历史记录」分为来自 Ledger 的「学习与变更」和脱敏的「系统运行」，按日分组，支持搜索、日期、来源和类型过滤。可从评价跳回原稿，从模型提案跳到审核或正式 Session。设置分为外观与显示、复习与打印、AI 识别、AI 助手、外部 AI/MCP、数据与存储、服务与运行，支持键盘切换。

## 数据与安全

- 所有录入、评分、修改都是追加到 `语文/.clms/ledger.db` 的哈希链提交，不改写旧记录；「设置 → 校验提交链」或 `python3 clms_engine.py --vault … verify` 可以检查完整性。
- 草稿（`drafts/*.json`）暂存，入库时才整份原子追加；原图保存在 `images/`，Ledger 保存领域关系与作文各阶段文本。
- 助手、审核和运行 SQLite 与 MCP Key 是辅助存储，不是学习事实源。运行记录只存编号、数量、状态和耗时，不存 Key、全文、图片或完整聊天。脱敏源码包覆盖新增模块/可选依赖，排除全部私有库和原图。
- 升级直接使用旧库，不清空 `.clms`，旧题目/材料/Session 编号保持；新增辅助表幂等创建。备份时复制整个 `语文/.clms` 目录。
- 服务默认只监听 `127.0.0.1`，写请求校验同源。Web 没有登录保护，不要用 `--host 0.0.0.0` 暴露到不可信网络。

## 命令行

「设置 → 服务与运行 → 重启程序」可按当前数据目录、地址和端口重新启动，服务上线后页面自动刷新。重启会中断正在进行的 AI 任务，已保存的数据保留，未完成任务可重试；请先保存正在编辑的内容。直接运行和 systemd 服务都支持。

```bash
python3 clms_engine.py --vault <目录> serve [-p 8472] [--host 127.0.0.1] [--open] [--mcp-port 18473] [--mcp-public-url URL]
python3 clms_engine.py --vault <目录> stats     # 统计摘要（JSON）
python3 clms_engine.py --vault <目录> verify    # 校验提交链
python3 clms_engine.py --vault <目录> export-source [-o 目录]   # 导出脱敏源码包
```

## 已知限制

- Agent 模式（工具调用、子代理委派、拍照批改）只在假模型上做过端到端测试，还没接真实模型验证；真实视觉模型的识别质量取决于模型本身，第一次使用建议拿一张清晰的卷子试一下。
- 已测桌面和 390px 浏览器布局，尚未在实体手机验证相机、软键盘和系统打印。Web 未实现账户/PIN 登录；外部 ChatGPT 账户与公网代理未实际联调。
