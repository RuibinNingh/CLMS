# 变更记录

## 0.6.0 · 2026-09-28 · 复习页重做：一次一道题、答题卡导航、复习助手按需查阅

- 复习页改成工作台：左栏一直是复习记录（进行中 / 已评完，带进度，悬浮出现打印、删除），不用再滚到页面最底下找；「确认安排」放到页头，「本次安排」和「从题库挑题」在宽屏上并排。
- 评分改成一次看一道题。左栏是「答题卡」：按材料列出题号，评过的按评分着色，对过答案还没评的用红笔虚线框标出，正在看的那道填墨蓝。题目区够宽时原文和题目并排、各自滚动，不够宽时题目在上、原文在下（按题目区的实际宽度判断，不会在 1600 左右把两列挤成细条）。原文没有自带段号时加段号。
- 自评更顺手：评分档和说明一直摆着，数字键 0–3 直接评，空格对答案，← → 换题，/ 问助手；评完显示下次复习的日期；反馈框随时可写，还没评分时先暂存，评分时一起写入。最后一道题会提示还有哪道没评。
- 复习助手改为按需查阅：不再每次把整篇原文和整道题塞进上下文，而是自己调用只读工具看题、读原文（可以只读几段，或按关键词找段落）、查以前的复习；多轮对话不再重复发原文。思考过程和每次查阅都显示在对话里，可以展开看它查到了什么；每条回答末尾显示查阅次数、用时和 token 用量。
- 可以引用卷面：在原文或题目里选中一段文字，点浮出的「引用」，就能针对这段提问；引用带着位置（第几段、第几题）一起发给助手。
- 上一轮发的作答照片，下一轮点「打分」时仍会发给模型。
- 模型不支持工具调用时，在「设置」里关掉 Agent 模式，复习助手会退回旧做法（整道题并进上下文）。
- 修正：改评分时，这道题原来写的反馈会被清空。
- 修正：录入准备阶段，关掉某一页的大图预览后，第二次按 Esc 关不掉页面管理窗口。
- 修正：录入准备阶段连续改页面（比如先拖动换序、紧接着填这页的说明）时，较早那次保存的回复如果晚到，会把刚填的说明冲掉，下一次保存还会把丢了说明的页面存回去。现在页面的保存排队按顺序发，只认最后一次的回复。
- 修正：系统开了「减少动态效果」时，准备阶段的页面条和输入框不再做入场动画（之前动画的终态会一直留在元素上）。
- 测试：端到端测试里有两处基线就会失败的步骤（上传后等页面占位、窄屏下切主题）已修正；PDF 路径加了上面那个竞态的确定性回归（故意让换序那次的回复晚到）；复习页部分按新界面重写，新增窄屏复习页检查；复习助手的单元测试会检查发给模型的每一轮请求里带了什么、没带什么。

## 0.5.0 · 2026-09-28 · 两种记忆曲线、推荐 + 挑题、复习助手、可扩展的题库

- 记忆机制分两类：默写、文言实词 / 虚词 / 文化常识是「记忆型」，照旧间隔重复；阅读、鉴赏、翻译等是「理解型」——做对一次（或连续两次「基本」）就算掌握，衰减慢，掌握后约 4 个月才抽查一次。因为重做同一道阅读题测的多半是记不记得答案，反复排它意义不大。已经「完整」过一次的阅读题会直接显示为已掌握。
- 安排复习改成「推荐 + 自选」：进页面就有推荐清单，每题写明理由（逾期几天、上次评分、新题几天没练、薄弱题型、掌握后抽查）；新题放得越久越往前排，薄弱题型优先补同题型的其它题，两天内刚做过的题不拿来提前复习，已在没做完的复习里的题不重复推荐。不想做的题可以移掉（自动换一道）、换一批、全部放回；下面可以从题库按状态、录入时间、最近练习、上次评分筛选后加入，加入的题一定排上。
- 评分页去掉顶部的「拍照交给 AI 批改」，右侧改为复习助手：跟着点中的题，可以随时提问、附作答照片、让 AI 打分或写反馈（流式、可停止）。AI 的评分和反馈只是建议，点「采用」才写入；还没评分时可以先把反馈填上，评分时一起写入。
- 题库为大量题目重做：左侧分面筛选（状态、记忆类型、添加时间、最近练习、上次评分、题型，每项显示题数），可按题或按篇浏览，分页加载，新增按出错次数 / 最近练习 / 最早录入排序、按题号搜索；批量加入复习、停用、恢复、删除；新增「复习记录」分页查看全部复习历史；详情显示记忆类型、上次评分、同一篇的其它题，可以直接加入复习。
- 长标题不再被截断：录入页材料的标题、作者、出处改成会换行的文本框（标题独占一行、作者和出处另起一行）；打印卷、复习页、题库里的篇名与出处也都换行显示。
- 修正：导出的脱敏源码包里，测试用的假密钥本身也被脱敏，导致包里的 `test_export_skips_data_and_redacts_key` 必然失败。

## 0.4.0 · 2026-09-28 · 打磨：居中输入框与过渡、用量圆环、可折叠侧栏、排版与动效

- 新录入、上传后确认页面、复习批改都从一个居中的大输入框开始：写的话就是补充说明，上方是可拖动排序、旋转、删页、加页的页面条。开始后输入框平滑落到对话底部，第一条消息滑入，AI 接着开始思考；入库后「录下一份」反向过渡回来。
- 输入框旁加了用量圆环：显示上下文占用；悬浮看速度（执行中是实时值）、首字延迟、主 / 子代理轮数、工具次数、累计 token。模型服务不返回用量时自动改为估算并注明。设置里可填上下文窗口。
- 录入记录可收起，主导航可收成图标窄栏，都会记住。
- 模型的回复按 Markdown 排版（粗体、列表、表格、代码、引用、链接），不再显示成一堆星号和横杠。
- 修正对话区被过长的工具摘要撑出横向滚动条；滚动条全局改成跟随主题的细条。
- 字体改为按平台挑系统里最好的界面字体与等宽字体（Windows 上代码不再落到 Courier）；删掉一个指向不存在文件的字体引用。
- 动效：新消息入场、展开箭头、展开内容淡入、进行中文字流光；「减少动态效果」时全部关闭。
- 修正：补充说明失焦保存与「开始」赛跑时偶发 400；执行结束后左侧录入记录立即刷新状态。
- 修正录入页的几处竞态：切到别的草稿或「新录入」时，还在路上的旧刷新会把界面拉回旧草稿；两次刷新乱序返回时界面短暂倒退；后台刷新恰好撞上「打开」时会把打开吞掉，停在开始界面。现在「打开」以最后一次为准，后台刷新遇到更新的请求或打开就作废。

## 0.3.0 · 2026-09-27 · Harness 式实时交互、准备流程、录入记录

- 对话改成 Harness 式时间线：模型的思考逐字出现（支持 `reasoning_content` 与 `<think>`），它说的话逐字出现，每次工具调用一行、点开看参数和结果（参数生成时实时显示）；子代理卡片点开是子代理自己的时间线；每次执行收尾显示轮数、工具次数、用时和改动。系统说明要求模型调工具前先说一句要做什么。
- 模型调用改为流式，草稿经 SSE（`/api/draft/events`）实时推送块与逐字内容，不再靠轮询等一个进度块；停止在流式读取中也立刻生效。
- 上传后不再直接执行：先到「准备」确认页序（拖动 / 箭头）、转正、删页、加页、写每页说明和补充说明，再「开始识别」或「每页一份，分别识别」；复习批改照片同样先确认再「开始批改」。旋转在发给模型前生效。
- 录入页左侧改为录入记录：按日期分段、搜索、分组（全部 / 进行中 / 待入库 / 已入库 / 回收站）、重命名、回收站（可恢复、可彻底删除）、加载更多；窄屏为抽屉。
- 后端：`drafts.py` 拆出 `draft_runs.py`（执行、插话、停止、恢复）与 `live.py`（实时通道）；新接口 `/api/draft/pages|start|rename|undiscard|delete|events`，`/api/drafts` 支持分组、搜索、分页。

## 0.2.0 · 2026-09-27 · Agent harness、子代理、记录增删改查、脱敏源码导出

- 录入对话直连工具调用的 Agent（对标 Pi agent-core）：模型通过工具逐个板块、逐道题读写草稿，不再一次吐出整份 JSON；执行记录实时显示每次工具调用；执行中可以插话、可以停止；一次 run 只占一版，可「回到修改前」。
- 大试卷：主代理通读全卷后 `delegate`，每个大题一个子代理，只告诉它板块、标题和页码；子代理只看自己的页、只改自己的板块，并发执行，进度以子代理卡片显示。
- Agent 还能查改题库（改、停用、删除、恢复）、增删改查复习记录、对着复习作答照片批改并写反馈，已入库的草稿也能继续聊；队列栏新增「新对话」。
- 题库：复习记录可补记、改评分、改反馈、撤销、恢复；删除的题可在「已删除」里恢复（新提交类型 `item.restore`）。复习页：评分可写反馈；「拍照交给 AI 批改」。
- 设置：Agent 模式开关（模型不支持工具调用时关掉，回到旧的一次性识图）、子代理并发、每次最多轮数；「导出脱敏源代码」（不依赖 Git，替换 API Key），命令行 `export-source`。

## 2026-09-27 · 录入执行动态

## 0.1.0 · 2026-09-27

首个版本，架构对标 OMRS 1.25.4。

- 录入：上传 / 粘贴 / 拖放图片，每张一份草稿（或跨页合成一份），后台排队识别；AI 拆出原文、小题、题型、分值、参考答案（区分图中答案与 AI 补写）、留白行数；默写按 `{书写区域n}` 模板 + 答案表录入、每个空一道题。
- 对话式校对：多轮修订、改动清单可点击定位并闪烁、回到修改前；草稿纸面可直接编辑（自动保存、可撤销）、添加小题 / 板块；入库前检查缺项。
- 去重：默写按答案汉字；阅读材料按原文哈希 + 二元组相似度；小题按题干（保留编号）。已有的题记「又错一次」。
- 复习：复习日（默认周二 / 五 / 日）对齐到期日；按时间预算排题、同篇材料合并；A4 打印（答题横线、默写下划线、同题多空合并一行、可附答案）；四档自评（默写三档），可撤销、改评。
- 概览、题库、设置页；浅色「答题卡」主题与深色暖石墨主题；窄屏布局。
- 工程：哈希链 Ledger、增量内存投影、ThreadingHTTPServer、路由表、无构建 ES 模块前端、`check_ui.py` 门禁、假模型、单测 + 真浏览器端到端测试。
